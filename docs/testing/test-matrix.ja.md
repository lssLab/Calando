# テストカバレッジ

<p align="center">
  <a href="test-matrix.md">English</a> · <a href="test-matrix.ko.md">한국어</a> · <a href="test-matrix.zh-CN.md">简体中文</a> · <strong>日本語</strong>
</p>

パブリック スイートは、ポリシーの決定からインストール、hook 配線、リカバリ、環境全体の調整までの製品パスをカバーします。

| エリア | 検証される内容 |
| --- | --- |
| 政策とブレーキ | `ALLOW`、`HOLD`、`DRAIN` の容量と低下率。 クッションの順序。 帰属; 間隔ごとに選択されるターゲット |
| プロセスの安全性 | PID と ID 再検証の開始、所有権の一時停止、一度に 1 つの候補、自動および手動リカバリ |
| Claude Code | hook マージ、サポートされているイベント、フェールオープン動作、インストールまたはアップデート後の接続診断 |
| Codex CLI | 7 つすべての hooks のパスとイベント、信頼性と有効化の診断、既存のセッションの接続 |
| Codex Desktop App | 共有 App Server 検出、論理スレッドの分離、正確/推論/blind candidates、複数のウィンドウ、サーバー世代の変更 |
| 設置して電源を入れる | Unix および Windows のインストール、更新、アンインストール、`on`/`off`、および既存のユーザー設定の保存 |
| Federation | カーネルローカル制御、同じ物理メモリのadmission共有、および古いピアまたは無効なピアの拒否 |
| 通知とセキュリティ | 正確な端末の検証、重複排除、オプションのルート、およびプライベート状態ファイルのアクセス許可 |
| リリースバンドル | 公開専用のソース アーカイブ、チェックサム、および必要なプラットフォーム バイナリ |
| リポジトリの安全性 | パブリックファイル許可リスト、個人パスや認証情報なし、英語、韓国語、簡体字中国語、日本語ドキュメントの一致、および有効な内部リンク |

GitHub Actions は、Rosetta 上の Linux x86-64、Windows x86-64、Apple Silicon macOS、および macOS x86-64 上の Rust ビルド、テスト、プラットフォーム コントラクトをチェックします。 オペレーティング システムの信号と実際のほぼ枯渇の境界は、ホストされたランナー上で常に安全に再現できるとは限らないため、決定論的なテストは、制限された物理マシンの検証と組み合わせられます。

計算および制御された測定結果については、[適応停止距離](stopping-distance.ja.md)を参照してください。
